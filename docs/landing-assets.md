# Landing page asset provenance

`frontend/public/images/purple-rose.jpg` is a locally served photograph from
[Arthur Rachbauer on Unsplash](https://unsplash.com/photos/purple-rose-flower-vYyHLDPKWd4),
downloaded from the official Unsplash image URL
`https://images.unsplash.com/photo-1548678756-aa5ed92c4796` on 2026-09-23.
It is used as the visual in the hero showcase and sticky scroll-driven rose
section under the [Unsplash License](https://unsplash.com/license). The
source image was not modified; CSS supplies the crop, tint, mask, and motion.

All other landing visuals are project-native HTML/CSS/SVG, not copied assets
from Dialedweb. The rose motion is a still-image treatment, not a claim that
the site has Dialedweb's original 3D flower animation.
