# Trends

BERTrend 0.4.18 is installed and imports on Python 3.13.11. The first X vertical slice does not yet run BERTrend models.

The current API exposes an explicitly labeled hashtag-frequency summary so clients have a typed trend-shaped response without misrepresenting it as BERTrend output. A later phase will add micro-batched BERTrend processing, persistence, velocity, acceleration, and signal status.
